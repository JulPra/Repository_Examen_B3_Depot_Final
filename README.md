# Repository_Examen_B3_Depot1
Convention de nommage des branches.
main : version stable du projet;
develop : branche dans laquelle les développements sont en cours;
feature/XXXX : branches qui contiendront les fonctionnalités des user stories;
lorsque le bouton "réserver" d'une séance est appuyé et dès qu'une page de paiement s'affiche, les valeurs ci-dessous sont simplement des valeurs pour tester le paiement : 
email : client@test.com;
via carte;
numéro : 4242 (quatre fois);
MM/AA : 1/30;
CVC : 123;
nom titulaire : Test;
la réservation est sauvegardée dans le fichier backend/src/data/reservations.json;
